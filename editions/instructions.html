Quick start

  1. Open chom.ps/admin/editions.html.
  2. Paste your GitHub token and click Load. (First time? See Connecting.)
  3. Click Edit on an item, or + Add item.
  4. Change what you like, then click Apply to list. Nothing is public yet.
  5. Click Save & publish. After about a minute, the live page shows the change.

Apply to list only changes the page you have open. Save & publish is the step that makes it live. If you close the tab before saving, you lose the changes.

Common jobs

I want to…Do this
Add a new book+ Add item. Leave Show under on Books. Fill in at least Title, then add a buy link.
Add a second formatEdit the book, + Add link, give it button text like “Paperback · Amazon”.
Add a recommendation+ Add item, set Show under to Recommended, pick a Category.

Shorten a long descriptionSet How much of the description shows to “An excerpt”.
Remove somethingDelete in the list, then Save & publish.

How the page works

Visitors see two sections, in this order:

Chomp Chomp Editions
Your own books. These are items with Show under set to “Books (main section)”.
Recommended
Things you like. Items set to Recommended appear here, sorted into the groups you define (such as For Further Reading and Kitchen). Every group starts closed, with a count and a Show button. A group with no items doesn’t appear.
Tag buttons
The row of small buttons near the top is built from every item’s tags. Clicking one shows only matching items and opens the groups that contain them. Click again to clear.
Disclosure line
Appears above any section that has an affiliate link. See Buy links.

Items appear in the order they are in your list, top to bottom. Hidden items and empty groups are skipped.

Connecting

Repository
Where the site lives on GitHub. Leave it as chomp-chomp-chomp/chomp.
Branch
Which branch to save to. Leave it as main, which is the live site.
GitHub personal access token
Your key to save changes. It’s a long code starting github_pat_. It is sent only to GitHub, never to this site.
Remember on this device
Keeps the token in this browser so you don’t paste it every time. Leave it off on a shared or work computer.
Load
Reads the current list from GitHub. Always click this first.

Making a token (once, or when it expires)

  1. On GitHub: your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it (for example “Editions admin”) and pick an expiration date.
  3. Under Repository access, choose Only select repositories and pick chomp-chomp-chomp/chomp.
  4. Under Repository permissions, set Contents to Read and write. Leave everything else alone.
  5. Click Generate token and copy it right away. GitHub only shows it once.

Page settings

These sit at the top of the editor, above the item list.

Page intro
The line of text under the header art on the Editions page.
Affiliate disclosure
The sentence shown above any section that contains an affiliate link. It should say that you may earn a commission, and for Amazon links it needs: “As an Amazon Associate I earn from qualifying purchases.”
Recommended groups
One group per line, in the order they appear on the page. Write Name | short description. The description shows under the group’s name and is optional. 
For Further Reading | These books hold up on their own merits.
Kitchen | Tools and equipment I use and trust.
Other
An item with no group, or a group that isn’t in this list, lands under “Other”. Renaming a group here does not rename it on items already in it. Open those items and pick the new name.

Items

Each row in the list is one book or recommendation. Small tags beside the title show how it is set up (recommended, collapsible, affiliate, and so on).

↑ ↓
Move the item up or down. This changes the order on the page.
Edit
Opens the item’s form below the list.
Delete
Removes the item from your list (it asks first). It is gone from the page once you Save & publish.
+ Add item
Starts a blank item.

Item fields

Basics

Title *
Required. The only field you must fill in.
Author
Shown under the title, followed by the Details if you add them: “Donnie Boman · Hardcover”.
Tags
Comma-separated words, like baking, bookshelf, C12 Bibliography. They become the filter buttons near the top of the page, and show on the item itself (except on Compact items). Use the same spelling every time, because “Baking” and “baking” are different buttons.

Where it shows

Show under
Books (main section) puts it under Chomp Chomp Editions. Recommended puts it in the Recommended groups.
Category
Appears only for Recommended items. Picks which group the item sits in.
Hidden
Keeps the item in your list but removes it from the page, and removes its tags from the tag buttons. Handy for drafts.

How much shows

Display
Full: cover, text and buy buttons all showing.
Collapsible: title, author, tags and buy buttons show. The cover and description sit behind a More link.
Compact: one tidy line with the title, author and links. Everything else is hidden, so the fields below don’t apply. Compact is good for long lists of recommendations. Collapsible is good for books with a lot of text.
How much of the description shows
All of it, or An excerpt with the rest behind More. The excerpt is the first paragraph. To end it somewhere else, put --more-- on a line by itself. Everything above shows, everything below is behind More. A single-paragraph description has nothing to hide, so no More link appears.

Content (hidden when Display is Compact)

Subtitle
A smaller line under the title.
Status badge
A small red label above the title, such as Available or Coming soon. Leave blank for none.
Details
Format and length, shown after the author. For example Hardcover, 240 pp.
Cover image URL
The web address of the cover image (starts with https://). Right-click a cover on your own image host and copy the image address. Shown beside the text on a computer and above it on a phone. On Collapsible items, it appears when More is opened.
Description
The text. A blank line starts a new paragraph. You can add links and light formatting; see Writing descriptions.

Buy links

Each link becomes one button. Keep these for places to buy. Put reviews and extra reading in the description instead.

Button text
What the button says. Name the format and the store: Hardcover · Lulu, Paperback · Amazon.
Price (optional)
Shows small inside the button, such as $28 + shipping. For Amazon, leave it off unless you keep it current. Amazon’s rules restrict showing prices that may be out of date.
Affiliate
Tick this on links that earn you a commission. It adds a visible “affiliate link” label, marks the link for search engines as sponsored, and makes the disclosure line appear above that section. Leave it unticked for your own Lulu and plain links.
Link address
The full web address, starting https://.
+ Add link / ×
Add another button, or remove one.
How the buy links appear
Automatic: 1 or 2 links show as separate buttons. 3 or more fold into one Purchase options button that opens a list with each format, store and price.
Always separate buttons: never fold them.
Always one “Purchase options” button: folds even 2 links.

Disclosure reminder. The disclosure line shows when any link is marked Affiliate, and also when a description contains an Amazon link. If you use Amazon Associates, keep the “As an Amazon Associate…” sentence in the Affiliate disclosure box.

Writing descriptions

You typeYou get
[a review](https://example.com)A link that reads “a review”.
<a href="https://example.com">a review</a>The same link, written as HTML.
**bold**bold
*italic*italic
a blank lineA new paragraph.
a single line breakA line break inside the same paragraph.
--more-- on its own lineThe end of the excerpt (when using excerpt mode).
  • Links open in a new tab. Only https://, http:// and mailto: links work.
  • Any other HTML (images, scripts, styling) is shown as plain text, on purpose. This keeps the page safe if you paste a blurb from somewhere else.
  • A link address that contains a closing bracket ) needs %29 instead of it.
  • Amazon links in a description are treated as possible affiliate links.

Example: an excerpt with a review link

Twelve recipes, one conspiracy, and a reading list that
isn't lying to you about everything.

--more--
Longer story about where the recipes came from.

Read [the first review](https://example.com/review).

When something goes wrong

The bar at the bottom of the admin says what happened. These are the usual messages:

You seeWhat it means and what to do
Rejected the tokenThe token expired, was revoked, or was pasted wrong. Make a new one.
Allowed to read but not changeThe token is missing Contents: Read and write, or doesn’t include this repository. Fix it on GitHub, or make a new token.
Can’t find the file, branch or repositoryCheck the Repository and Branch boxes. A token that doesn’t include the repo gives this message too.
File changed since you loaded itSomething else saved first (another tab, or an edit on GitHub). Reload, then redo your change.
Branch protection ruleGitHub won’t accept saves straight to that branch. Use a different branch or ask for the rule to be changed.
Admin page is out of dateYour browser is showing an old copy. Saving is switched off to protect your data. Add ?v=2 to the end of the address and try again.
“[object Object]” in the groups boxAlso an old cached copy. Don’t save. Reload with ?v=3 on the end.

Your change isn’t showing on the live page

  • Wait a minute or two after saving. The site has to rebuild.
  • Then hard-refresh, or add ?v=1 to the end of the page address. Phones hold on to old copies.
  • Check the item isn’t Hidden, and that you clicked Save & publish, not just Apply to list.

You can tell which version of the admin you have from the “Admin version” label under its title.

Good habits

  • Load before you start, and Save & publish when you’re done. Avoid editing in two tabs at once.
  • Keep buy buttons for buying, and put reviews and further reading in the description.
  • Tick Affiliate only on links that really earn you something, and keep the disclosure sentence accurate.
  • Use the same spelling for tags and group names.
  • Don’t leave the token remembered on a shared computer.
